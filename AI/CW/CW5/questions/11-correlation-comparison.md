# Problem 11: Comparing Multiple Correlations

Calculate the correlation coefficient separately for each of the following pairs:

1. `CustomerRating` and `DeliveryMinutes`
2. `OrderValue` and `ItemsCount`
3. `OrderValue` and `DiscountPercent`
4. `OrderValue` and `DeliveryMinutes`

Then answer the following:

1. Report the sign of each of the four correlation coefficients.
2. Which pair has the strongest positive relationship?
3. Which pair has the strongest negative relationship?
4. Which pair has a correlation coefficient closest to zero?
5. For the pair with the strongest relationship, draw a Scatter Plot and compare the numerical result with the visual pattern in the plot.
