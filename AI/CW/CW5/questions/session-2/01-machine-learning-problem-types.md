# Problem 1: Identifying the Type of Machine Learning Problem

## Required Dataset

The dataset required for this session is:

`student_performance_session2.csv`

## Dataset Columns

* `StudentID`: Student identifier
* `StudyHours`: Number of hours spent studying
* `AttendancePercent`: Percentage of class attendance
* `PracticeTests`: Number of practice tests taken
* `PreviousScore`: Student's previous score
* `FinalScore`: Final score
* `Passed`: Whether the student passed or failed

## Tasks

For each problem, identify which type of learning is appropriate:

* Supervised Learning — Regression
* Supervised Learning — Classification
* Unsupervised Learning
* Reinforcement Learning

1. Predicting a student's final score.
2. Predicting whether a student will pass or fail.
3. Grouping students based on their study patterns without previously provided labels.
4. Training an intelligent agent to select an appropriate exercise by receiving rewards and penalties.

Then answer the following questions:

1. What is the main difference between Regression and Classification?
2. Which column in this dataset could be the Target for a regression problem?
3. Which column could be the Target for a classification problem?
