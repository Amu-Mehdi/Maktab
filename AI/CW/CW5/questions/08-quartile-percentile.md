# Problem 8: Quartiles and Percentiles

For the `OrderValue` column, use `quantile()` to calculate the following:

* Q1, or the 25th percentile
* Q2, or the 50th percentile
* Q3, or the 75th percentile
* The 90th percentile

Then answer the following questions:

1. Is Q2 equal to the median? Compare the two outputs.
2. Approximately what percentage of orders have an order value less than or equal to Q1?
3. Approximately what percentage of orders have an order value less than or equal to Q3?
4. What boundary does the 90th percentile represent among the order values?
5. If an order has a value above the 90th percentile, is it among the 10% most expensive orders or the 90% least expensive orders?
6. Is every value above the 90th percentile necessarily an outlier? Compare this with the IQR method.
