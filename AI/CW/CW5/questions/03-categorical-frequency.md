# Problem 3: Analyzing the Frequency of Categorical Variables

Using `value_counts()`, calculate the following:

1. The number of orders placed in each city.
2. The number of orders in each product category.
3. The frequency of each payment method.
4. The number of returned and non-returned orders.

Based on the outputs, answer the following questions:

1. Which city has the highest number of orders?
2. Which product category has the lowest number of orders?
3. What is the most frequently used payment method?
4. How many orders were returned?
5. Are there more non-returned orders than returned orders?
